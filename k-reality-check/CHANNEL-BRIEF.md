| 시리즈 | 성격 | 예시 |

## 4. 영상 포맷 (고정 스펙)

- **길이**: 약 3분 / **1920×1080, 24fps, 16:9**
- **구조**: 인트로(훅+근거 예고) → 본론 6개 항목(각 액트) → 아웃트로(리캡+구독 유도)
- **액트 구성**: 제품카드 3초 → 클립 몽타주(4초 단위, 반복 금지) → 데이터카드 5초
- **상단 리본 자막**: TRAP=빨강, LOCAL PICK=초록, 인트로=시안, 아웃트로=검정
- **비주얼**: "Vivid Pop" — 네온 옐로/크림슨/네온 그린/시안, 밝은 하이키. 다크톤 금지
- **오디오**: Leo 보이스 나레이션만 (AI 클립 음악·효과음 사용 금지). BGM은 유튜브 오디오 라이브러리에서 수동 추가
- **자막**: 영어 SRT 별도 파일, 한 줄씩(≤48자), 실제 발화에 정렬

## 5. 에셋 원칙

- **실물 제품·매장이 나오는 컷은 실사 필수** (AI는 실제 브랜드 패키지를 못 그림)
- 우선순위: 실사 영상 > 실사 사진 > AI 영상
- 사용자가 직접 촬영/업로드 → 저작권 체크(워터마크·출처·대사와 제품 일치) → 슬롯 배정
- AI 영상은 이미지 먼저 만들어 확인받고 → 승인된 것만 영상화

## 7. 기획 대화에서 정할 것

1. **시리즈 선택**: Reality Check(검증) vs Local's Best(추천)
2. **주제**: 구체적 소재 6개 (EP1과 중복 없이)
3. **근거 데이터**: 각 항목마다 인용할 실제 출처 (여론·판매·랭킹). 없으면 주제 교체
4. **훅**: 첫 5초에 시청자를 붙잡을 문장
5. **에셋 계획**: 어떤 컷을 직접 촬영할지 / AI로 만들지 → 크레딧 견적
6. **패키징**: 제목 후보 3, 썸네일 컨셉, SEO 설명

## 8. 대화 규칙

- 크레딧이 드는 생성 작업은 **사용자의 명시적 GO 이후에만** 실행
- 사실 관계(한국 음식·문화 명칭, 실제 유행 여부)는 **사용자가 로컬 검증자**다. 애매하면 물어본다
- 근거 없는 데이터를 지어내지 않는다. 출처가 불확실하면 표현을 낮추거나 소재를 바꾼다
