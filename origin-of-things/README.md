# 사물의 기원 (가제) — AI 다큐 유튜브 채널

일상 사물의 기원을 다루는 무인물(無人物) AI 다큐 채널. 한국어 원본 + 영어 오디오 트랙.

## 문서

| 파일 | 내용 |
|---|---|
| `docs/channel-plan.html` | 채널 설계서 — 포맷, 훅 설계, 서사 골격, 비주얼 시스템, 소재 20편, 제작 파이프라인, 작업 규칙 |
| `docs/ep01-microwave-script.html` | 1화 전자레인지 대본 v2 — 블록별 나레이션·컷 지시, 팩트체크 표, 부족한 점 |
| `ep01/script-blocks.json` | 1화 대본 데이터(블록·타임코드·글자수). 씬 분할과 조립 스크립트가 읽는 원본 |
| `ep01/vo-test.md` | 한국어 보이스 5종 실측 결과 |

HTML 문서는 브라우저로 열면 된다.

## 확정 사항

- **포맷** — 5~10분, 무인물, 16:9, 720p 생성 → 1080p 출력, 30fps
- **모델** — 영상은 `gemini_omni_flash_1_1` (Veo Omni 계열) 하나만. **이미지 생성 모델은 쓰지 않는다**
- **씬** — 8초, 비트 최대 2개. 카메라는 테이블톱 문법(오빗·탑다운·매크로·랙포커스·횡이동). 항공 부감·크레인 금지
- **스틸** — 생성하지 않고 클립에서 프레임을 추출해 쓴다 (톤 일치)
- **계측선** — 수치와 색상은 모델에 맡긴다. 화면 수치가 틀려도 진행한다. 사실은 나레이션이 책임진다
- **언어** — 한국어 원본 + 영어 오디오 트랙. 채널은 하나. 화면 텍스트는 숫자·영문만 (한글 번인 금지)

## 작업 규칙

1. 대본을 쓴 다음 **반드시 부족한 점 목록과 팩트체크 표를 함께** 낸다. 미확인 항목이 남으면 제작에 들어가지 않는다
2. 씬은 8초 2비트, 모델 하나 고정
3. 산출물은 **한국어 설명 + 영문 코드블록 + 설정 표 + 글자수**로 내고, 기존 규칙과 충돌하는 지점을 위험도와 함께 먼저 알린다
4. **힉스필드 크레딧은 매번 사전 승인을 받고 쓴다.** 테스트 1회도 예외 없음

## 로컬에서 이어서 하기

```bash
git clone <repo> && cd dooroolee/origin-of-things
```

필요한 것:

- Claude Code + 힉스필드 MCP (클라우드에서 쓰던 것과 동일)
- `ffmpeg` — 프레임 추출, 조립, 리사이즈
- 편당 여유 디스크 2GB 정도

클라우드 환경에서는 생성 결과를 재생할 수 없고 외부 자료 접근이 제한되므로,
**생성·다운로드·조립·검수·업로드는 로컬에서** 한다.
소재 조사·대본·팩트체크·프롬프트 작성은 어디서 해도 된다.
