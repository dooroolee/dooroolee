## 판단

- **Reid 탈락** — 7자/초는 다큐 톤이 아니다
- **미드롤이 붙는 8분을 넘기려면 Grady가 유일** (7분 52초 + 여백 12% = 8분 48초).
  Arthur는 7분 59초로 경계선에 걸린다
- 속도는 `speech_rate` 파라미터로 조정 가능하므로,
  **목소리가 마음에 드는 쪽을 고르고 속도는 나중에 맞춘다**
- 최종 판단은 실제 청취. 샘플 wav는 저장소에 넣지 않았다 (재생성 비용 6크레딧)

## 재생성 방법

`generate_audio_batch` / model `seed_audio` / `voice_type: "preset"` + 위 `voice_id`.
프롬프트는 `script-blocks.json`의 첫 블록(role "훅") 텍스트.

### 따라오는 결과

| | 기존 계획(5.0자/초 가정) | Desmond(5.56자/초) |
|---|---|---|
| 순수 발화 | 438초 | **394초** (6분 34초) |
| 여백 12% 포함 | 496초 = **8분 17초** | **447초 = 7분 27초** |
| 8분 선 | 넘김 | **못 넘김** |
| 미드롤 | 3개 (2:39 / 4:19 / 6:51) | **0개** |
| 8초 씬 수 | 약 62씬 | **약 56씬** ← 6씬 감소 |

- **미드롤 3개는 삭제한다.** 이건 새 결정이 아니라 이미 적혀 있던 규칙의 적용이다 —
  대본 문서 §01: 「8분 아래로 내려가면 미드롤 없이 간다. **길이를 맞추려고 대본을 늘리지 않는다**」
  → `script-blocks.json`의 `role: "미드롤 ①②③"` 블록은 **훅 2·훅 3 앞의 «구조적 전환점»이기도 하므로
  블록 자체는 남기고 광고 슬롯 의미만 뗀다.** 컷 전환 지점으로는 여전히 유효하다.
- **씬이 6개 줄어 영상 생성 크레딧도 그만큼 준다.**
- ⚠️ 위 숫자는 **훅 127자 실측에서 외삽한 것**이다. 2,190자 전체를 한 번에 읽히면
  문장 사이 호흡이 누적되어 달라질 수 있다. **타임코드 확정은 전체 VO 실측 뒤에 한다**(README §다음 작업 2).
