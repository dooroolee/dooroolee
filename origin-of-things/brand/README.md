# 안쪽의 세계 : Inside the Box — 브랜드 자산

전부 시스템 폰트로 직접 조판. **크레딧 0.** 생성 모델을 쓰지 않았다.
문구·색·서체만 바꿔 다시 뽑을 수 있다 → `build.py`

## 확정 자산 (2026-09-16 · 배너 C1 · 심볼 B)

| 파일 | 규격 | 용도 |
|---|---|---|
| `banner_2048x1152.png` | 2048×1152 | 유튜브 채널 배너 |
| `profile_800x800.png` | 800×800 | 유튜브·인스타 공통 프로필 |
| `watermark_youtube_150x150.png` | 150×150 **투명** · 15KB | 유튜브 **동영상 워터마크**(브랜딩 탭) |
| `watermark_capcut_wordmark.png` | 1402×277 투명 | CapCut 번인 — 심볼 + 채널명 + 핸들 |
| `watermark_capcut_plain.png` | 870×245 투명 | CapCut 번인 — 심볼 + 채널명만 |

채택되지 않은 시안은 `_alt/`에 보관(배너 A·B·C2·C3 · 심볼 6종 비교 시트 · 워터마크 대안 2종).

## 디자인 스펙

- **서체** — 한글 **Pretendard**(사용자 폰트 폴더 설치본) · 영문·숫자 **Bahnschrift**(윈도우 기본)
  ⚠️ 두 서체 다 **이 PC에 설치돼 있어야** `build.py`가 그대로 돈다. Pretendard가 없으면
  Noto Sans KR로 자동으로 떨어지는데 **글자 인상이 달라진다**
- **색** — 종이 `#EFECE5` · 잉크 `#16181A` · 스틸 `#8A9099` · **계측 앰버 `#D8871F`**
  → 채널 비주얼 시스템의 차별화 점검 ①②가 그대로 색이 됐다 — **밝게 · 계측선은 앰버**
- **배너 C1 「분해도」** — 상자가 세 겹으로 열리는 라인아트.
  **분해도는 안전영역 «밖»에 둔다** — 모바일에서는 글자만 보이고, 데스크톱·TV에서 분해도가 드러난다
- **심볼 B 「분해」** — 뚜껑이 수평으로 떠 있는 아이소메트릭 상자. 배너의 분해도와 같은 문법이다.
  뚜껑만 앰버 — **「열린 것」이 유일한 강조점**

## 규격 메모

- **배너 안전영역**: 중앙 **1235×338** 안에만 글자. 그 밖은 모바일에서 잘린다.
  데스크톱 2048×423, TV는 전체 노출. 업로드 후 **「모든 기기에서 미리보기」**로 확인한다
- **프로필**: 원형 크롭된다. 댓글에서는 48px까지 작아지므로 모서리 여백을 크게 뒀다
- **유튜브 동영상 워터마크**: 1MB 이하 PNG/GIF/BMP/JPEG. 플레이어 우하단에 **약 60px**로 표시되고
  클릭하면 구독이다. 표시 시점은 「동영상 전체」

## ★ 워터마크에 종이색 테두리가 있는 이유 ★

**배경을 지우면 대비도 같이 사라진다.** 심볼은 잉크(거의 검정)라 이 채널의 밝은 화면 위에서는
선명하지만, **전쟁·야간 씬처럼 어두운 컷 위에서는 윤곽이 통째로 죽는다.**

```
해결   획 둘레에 종이색 테두리를 한 겹 깐다 (build.py의 halo)
결과   밝은 화면 — 잉크 선이 읽힌다  /  어두운 화면 — 테두리가 형태를 잡아준다
```

한쪽 화면만 쓸 거라면 `_alt/`의 대안을 쓴다 — `wm_150_no_halo.png`(밝은 화면 전용 · 가장 깔끔) ·
`wm_150_ivory.png`(어두운 화면 전용 · 선 자체가 아이보리).

## 영상 번인 운용

전체 구간에 깔지 않는다. **마지막 클로징 2~3초에만** 페이드인, 불투명도 70~80%.
다큐의 몰입을 깨지 않으면서 출처만 남기는 것이 목적이다.
⚠️ **썸네일 한글은 CapCut에서 사용자가 얹는다** — 생성 클립에 한글을 번인하지 않는 규칙과 별개다.

## 재생성

```bash
python build.py
```
