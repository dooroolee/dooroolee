## 전제

- **모든 가게명과 숫자는 예시(placeholder)다.** 조사 단계에서 실제 값으로 교체한다.
  리듬과 문장 길이를 잡기 위해 실제처럼 써 뒀을 뿐이다.
- 나레이션은 영어(Leo), 자막은 영어 SRT (한 줄 ≤42자).
- **카카오맵은 쓰지 않는다** (약관상 영리 목적 이용 금지). 한국 앱 지표는 네이버만 사용하고,
  화면 표기는 `Naver` 또는 `Korean app`으로 통일한다.
- 지도 화면은 네이버·구글 모두 사용. **구글은 출처 표기 필수**, 스트리트뷰는 캡처 금지.
- **지표는 재구성하지 않고 실제 화면을 깐다.** 깔끔한 카드만 쓰면
  "그 숫자 네가 만든 것 아니냐"는 의심을 받는다. 근거로 승부하는 채널에서는 치명적이다.
  → 실제 캡처를 바탕에 깔고, 그 위에 스포트라이트와 영어 라벨을 **주석으로 얹는다.**
- **네이버 화면은 한글 그대로 노출한다.** 시청자가 못 읽는 게 요점이다.
  "이건 내 앱이 아니구나"를 즉각 느끼게 하는 것이 이 편의 주제다. 번역은 아래에 붙인다.
- **캡처마다 `as of July 2026` 날짜를 박는다.** 평점·리뷰 수는 변한다.
- **가게별 음식 컷은 반드시 그 가게의 실제 리뷰 사진을 쓴다.**
  포토코리아 사진은 일반 떡볶이지 그 가게 떡볶이가 아니다.
  특정 가게를 소개하며 남의 사진을 쓰면 실제 데이터를 쓰려던 취지가 통째로 무너진다.
  포토코리아·AI는 **인트로/아웃트로 같은 일반 맥락에서만** 쓴다.
- **강조는 색이 아니라 대비로 한다.** 캡처를 살짝 어둡게 깔고 강조할 곳만 원래 밝기로.
  색으로 강조하면 어떤 색을 골라도 구글·네이버 UI 중 하나와 부딪힌다.

## 표기 규칙

| 기호 | 의미 |
|---|---|
| `[명동-T]` | 명동 관광객집 (Tourist) |

| ▸ | 화면 전환 |

**"카드"의 정의 (중요)**

이 문서에서 `구글 카드` · `네이버 카드`는 **디자인한 그래픽이 아니라
실제 앱 캡처 + 그 위의 주석 레이어**를 뜻한다.

```
┌────────────────────────────────┐
│  [실제 구글 지도 캡처 — 그대로]   │  ← 바탕. 검증 가능한 증거
│                                │
│    ┏━━━━━┓                     │
│    ┃ 4.6 ┃ ← 스포트라이트        │  ← 주석. 어디를 볼지 지시
│    ┗━━━━━┛   (주변만 어둡게)     │
│                                │
│  2,340 reviews                 │  ← 영어 라벨
│  82% not in Korean             │
│                    as of Jul 2026│  ← 날짜 (필수)
└────────────────────────────────┘
```

`가게 카드`(소개 화면)만 순수 자체 제작 그래픽이다.

**리뷰 인용 화면 (이 편의 핵심 자산)**

가게마다 **한국인 리뷰 3개**를 한 화면에 쌓고, 스포트라이트만 순차 이동시킨다.
하나씩 따로 띄우면 시간을 너무 먹는다.

```
┌──────────────────────────────────────┐
│ [네이버 리뷰 캡처 — 한글 3개 그대로]     │
│                                      │
│ ▸ 관광지 가격이죠                      │  ← 스포트라이트 1
│   "Tourist prices."                  │
│   양이 너무 적어요                     │  ← 스포트라이트 2
│   "Portions are small."              │
│   한 번이면 충분한 듯                  │  ← 스포트라이트 3
│   "Once is enough."                  │
│                    as of Jul 2026    │
└──────────────────────────────────────┘
```

**왜 3개인가** — 1개는 일화지만 3개가 같은 말을 하면 **패턴**이 된다.
"누가 그렇게 말했대"와 "다들 같은 말을 한다"는 근거의 성격이 다르다.
한글 원문이 보이는 것이 증거이고, 영어 번역이 전달이다. 둘 다 필요하다.

**상단 표시 규칙** — 진행 바 + 핵심 숫자 (잠정, 렌더 확인 후 재검토)

판정어는 쓰지 않는다. 6칸 진행 바가 판정 색으로 채워지고, 오른쪽에 숫자 하나만 뜬다.

```
칸2                                      칸4 (반전)
▬░░░░░              82% NOT KOREAN      ▬▬▬░░░           NAVER 4.6
빨                                       빨빨초

칸8 (아웃트로 — 자동 리캡)
▬▬▬▬▬▬
빨 빨 초 초 초 초
      ↑ 서촌 관광객집. 여기만 튀는 게 이 영상의 논지
```

- 색 의미: **빨강 = 과대평가됨 / 초록 = 검증됨** (소재 이름이 아니라 판정 결과)
- 인트로 = 시안 / 아웃트로 = 검정
- 칸4가 관광객집인데 초록인 것은 예외가 아니라 **정상 동작**이다


### 설계 메모
- **가게 이름이 아니라 규칙을 남긴다.** 한국에 안 오는 시청자도 가져갈 게 있어야 한다.
- VO 1번의 **"Eighteen Korean reviews"**가 이 편의 작업량을 한 마디로 증명한다.
  숫자를 말하는 것만으로 "대충 만든 게 아니다"가 전달된다.
- 4번 문장으로 예외를 인정한다. 이게 빠지면 앞의 반전이 무의미해진다.
- 6번은 다음 편 예고 겸 시리즈화 선언. (korean fried chicken = 미국 월 87,000 검색)

### 리뷰 3줄 고르는 기준
```
✓ 짧을 것 — 영어로 옮겼을 때 한 줄(42자)에 들어갈 것
✓ 서로 다른 사람이 쓴 것
✓ 관광객집: 같은 지적이 반복되는 것으로 3개  → "패턴"이 보여야 함
✓ 로컬집: 단골·일상·오래됨을 드러내는 것
✗ 욕설·인신공격·특정인 언급이 들어간 것
✗ 지나치게 긴 것 (자막 두 줄 넘어가면 탈락)
```

### 가게 선정 기준
```
관광객집: 구글 평점 4.5+ / 비한국어 리뷰 비율 70%+ / 관광 동선상 위치

단, 서촌 관광객집만 예외:
  네이버 평점도 4.5+ 인 곳을 골라야 칸4 반전이 성립한다.
  → 이 조건에 맞는 곳을 먼저 찾고, 나머지 두 지역을 맞추는 게 빠르다.
```
